kota-app is a Discord bot that Takuma Homma (mataku) built and uses for personal purposes only. It is not offered to any other users.

## Google Drive Integration

kota-app integrates with Google Drive to save invoice files (xlsx), generated by commands I run in Discord, to my own Google Drive. It uses only the `drive.file` scope, so it can access only the files and folders that kota-app itself has created.
